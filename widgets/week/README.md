# Week Agenda

The coming days from your calendar, grouped by day (`11/4 水 明日`, holiday names in red), each
event with its start time (or 終日) and calendar colour. Long days end with `ほか N 件`. The widget
hides itself when there is nothing coming up.

- Signals: `time`, `calendar`, `holidays` (opt-in `providers.holidays`; all-day events that duplicate
  a holiday are skipped).
- Settings: `days`, `max_rows`, `include_today`.
