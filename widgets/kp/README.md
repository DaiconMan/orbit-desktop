# Space Weather

The planetary Kp index from NOAA SWPC: the latest value large, labelled 静穏 / やや活発 / 磁気嵐 /
強い磁気嵐, with 24 three-hourly bars (amber from Kp 4, orange from Kp 5) covering three days.
At Kp 5+ an aurora hint is shown. Hidden while there is no data.

- Signals: `kp` (opt-in `providers.kp`).
- Settings: `aurora_hint`.
- Uses the shared `.big` / `.vbars` / `.axis` styles from the SDK module kit.
