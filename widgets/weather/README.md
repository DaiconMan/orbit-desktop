# Weather

Current conditions, the next 12 hours and the next days.

- **needs:** `weather` (the host fetches Open-Meteo for `providers.location`; no API key)
- **settings:** `hour_step`, `days`, `show_place`, `show_rain`, `show_attribution`
- **Attribution:** Open-Meteo data is licensed CC BY 4.0. The widget shows
  "Weather data by Open-Meteo.com" by default; if you turn it off, credit Open-Meteo elsewhere.
