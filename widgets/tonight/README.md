# Tonight

Tonight's sky in a few lines: the Moon (phase glyph, traditional Japanese name, age, illuminated %),
the naked-eye planets currently above the horizon (brightest first), the ISS (altitude, or distance
when below the horizon), the next annual meteor shower peak and today's sunrise / sunset.

- Signals: `time`, `location`, `iss` (opt-in `providers.iss`), `weather` (sunrise / sunset).
- Planet and Moon positions are computed in the widget (Schlyter's simplified orbital elements, ~1°).
- Settings: `iss`, `meteors`, `sun` toggle their rows.
