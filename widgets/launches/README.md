# Rocket Launches

The next upcoming launch: mission name, date / time, rocket, provider and site, a large T− countdown
and its status (GO, 未確定, 未定, …) in the header. The following launches are listed underneath.
A launch stays as T+ for an hour after lift-off. Hidden when nothing is scheduled.

- Signals: `launches` (opt-in `providers.launches`, The Space Devs LL2), `time`.
- Settings: `more` (default 3).
