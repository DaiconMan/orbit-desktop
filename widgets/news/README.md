# News

The latest headlines from the RSS feed of the news provider, each wrapped to at most two lines,
with its publication time. The header shows the source label and how long ago the feed was fetched.
Hidden while there are no items.

- Signals: `news` (opt-in `providers.news`), `time`.
- Settings: `count` (default 5), `source_label` (default `NHK`).
