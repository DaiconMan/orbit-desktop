# Rain 2h

Total precipitation expected in the next 2 hours, when it starts ("15分後から雨" / "いま降っています")
and eight 15-minute bars. The widget is hidden while no rain (≥ 0.05 mm per 15 min) is expected.

- **needs:** `weather` (uses `minutely_15.precipitation` from Open-Meteo, CC BY 4.0)
- **settings:** none
