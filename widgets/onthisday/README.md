# On This Day

今日は何の日: up to three observances for today, then three events from history, one each from the
early, middle and recent part of the list (picked with a date-seeded random number, so the choice is
stable for the whole day). Hidden until data for today has arrived.

- Signals: `onthisday` (opt-in `providers.onthisday`), `time`.
- Settings: `max_chars` (default 46), `min_year` (default 1600).
