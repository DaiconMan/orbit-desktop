# Ops (personal / unofficial)

Four tiles: GitHub review requests, PRs with failing CI, RFCs awaiting approval (with how many need
your own action) and running Claude Code sessions, followed by the RFC ids, the session folders and a
meter of the weekly Claude usage left with its reset time.

**This widget shows personal and unofficial data.** `rfc` lists documents in your own approval repo,
`sessions` lists the folder names of local Claude Code sessions, and `claudeUsage` reads an
undocumented field of `~/.claude.json` (not affiliated with Anthropic; may break at any time). Each of
these is an opt-in provider.

- **needs:** `github`, `rfc`, `sessions`, `claudeUsage` (all sensitive / opt-in)
- **settings:** none
